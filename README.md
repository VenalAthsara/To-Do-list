# To-Do List Web Application

A responsive and interactive To-Do List application designed to help users organize, track, and complete daily activities efficiently.

## 🚀 Features
* **Interactive Dashboard:** Main landing page with custom animations and responsive layout.
* **Task Management:** Easily create new task lists and view completed tasks.
* **Custom Styling:** Clean UI powered by custom CSS animations for smooth transitions.

## 🛠️ Built With
* **HTML5** - Page structure and multi-page routing (`New List`, `My List`, `Completed Tasks`, etc.)
* **CSS3** - Custom styling and animations (`To-do list CSS.css`)
* **JavaScript (ES6)** - Dynamic page interactions and task logic (`To-do list Javascript.js`)

## 📁 File Structure
* `To-do list HTML.html` - Main landing page & dashboard
* `New List.html` - Interface to create new task items
* `My List.html` - Overview of active tasks
* `Completed Tasks.html` - History of completed items
* `Contact.html` & `App,Software.html` - Auxiliary pages
* `To-do list CSS.css` - Global stylesheet & animations
* `To-do list Javascript.js` - Core application script

## 💻 How to Run
1. Clone or download this repository.
2. Open `To-do list HTML.html` in any modern web browser (Chrome, Firefox, Edge).
